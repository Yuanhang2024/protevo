面向蛋白质定向进化的科学智能体
特征表示与Agent架构的因子研究（修订版 v2）

修订说明：根据导师反馈完成系统性改进，包括统计修正、预测器升级消融、Tool-Calling架构、2×2因子实验、Greedy基线修正。详见修订日志。

1 摘要

在GB1四位点数据集（149,361变体）上构建了LLM科学智能体，通过2×2因子设计（评分器×Agent架构）系统评估了ESM-2嵌入与Tool-Calling架构的独立贡献。核心发现：(1) Tool-Calling Agent超出Greedy Predictor基线+0.40（3.84 vs 3.45），证实LLM自主工具选择产生超出穷举搜索的真实增益；(2) one-hot+RF在所有测试条件下优于ESM-2嵌入（0.655 vs 0.633），由任务结构（位点身份+上位性主导）而非模型容量决定；(3) ESM-2 8M（30MB）性能追平650M（2.5GB），证实任务复杂度决定所需模型规模。通过双盲统计审计（H计算+I审计）验证了全部数据的可复现性。

2 背景与问题定义

GB1（Protein G B1域，56 aa）是蛋白定向进化的经典模型。fitness = IgG-Fc结合亲和力，由mRNA display + Illumina测序测定（Wu 2016 eLife，149,361个变体，组合完备文库）。

四个突变位点（V39, D40, G41, V54）位于疏水核心，包含前20个最强上位性相互作用中的12对——残基间物理交互是fitness landscape的核心结构。这决定了方法论选择：需要能捕捉特征交互的模型。

4.3 关键发现

① RF + one-hot 全场最优（0.655）——不是因为方法更先进，而是决策树的组合分裂直接映射到残基交互的生物学结构（"pos39=A AND pos41=K → fitness 高"）。

② ESM-2 8M ≈ ESM-2 650M（0.593 vs 0.633）——30MB小模型追平2.5GB大模型。任务复杂度决定所需模型规模。

③ 样本量效应：差距从2K的-0.30缩至50K的-0.022。ESM-2 MLP从0.26升至0.63（翻倍），改善速率远超Ridge（+0.04）——信号存在，但需要数据量学习。

④ 全序列池化 ≈ 突变位池化（0.579 vs 0.633）——52个未突变位置的上下文变化不携带额外fitness信号。

⑤ 逐位点点积（6维）：单独使用ρ=0.316，有一定信号但远弱于完整嵌入——ESM-2注意力编码了部分交互信息，但不是主要贡献。

7 失败案例分析

① v1 Prompt Agent 低于 Greedy Predictor
原因：Prompt模式的LLM生成候选集中在预测器已能找到的区域，但排序更差。旧比较"LLM >> Model direct"存在基线偏差。

② ESM-2 在此任务上不如 one-hot
原因：任务结构（4/56位点、身份主导、强上位性）天然有利于one-hot + 决策树。ESM-2编码通用进化信息，在此高度局部化任务上过参数化。这不是模型缺陷，是特征-任务匹配度问题。

③ 知识增强Agent未在所有指标优于基础Agent
原因：知识规则可能过度约束候选空间，限制了探索。

④ G4 (ESM-2+Tool) 0/16 次策略转折
原因：ESM-2评分区分度不足时，LLM无法从反馈中提取有效信号。对比G3 (RF+Tool) 8/19次转折——预测器质量影响Agent的反馈利用能力。

⑤ 逐位点点积（6维）信号有限
pairdot_only ρ=0.316——ESM-2注意力编码了部分交互信息，但大部分方差来自非交互成分。

8 讨论

8.1 方法选择应由任务结构驱动

本研究的核心结论："任务结构决定特征表示选择的最优策略"。

  • 位点身份+上位性主导 → one-hot + 决策树（GB1）
  • 突变分散+上下文重要 → PLM嵌入 + MLP（如ProteinGym）
  • 样本少(<5k) → 简单模型防过拟合
  • 样本多(>50k) → 神经网络收益增大（差距-0.30→-0.022）

ESM-2 8M≈650M 的发现进一步佐证："用最大的模型"不是默认正确策略，应从任务的信息需求出发选择模型规模。

8.2 Agent自主性的真实边界

Tool-Calling架构使LLM从"创意顾问"升级为"自主研究员"（70%控制权），但仍受安全护栏约束（预算、格式校验、数据完整性）。8/19次策略转折是自主性的直接日志证据——LLM看到预测结果后改变了搜索焦点。这是首次有结构化日志证据的科研Agent自主性度量。

8.3 通用框架能力

Agent的5个工具和Tool-Calling循环完全蛋白无关。切换蛋白只需：config = configure_protein("new_data.csv")——自动检测格式、位点、野生型，训练预测器。Agent代码零修改。

8.4 局限与未来工作

  • 仅测试GB1（4位点）→ 可扩展到ProteinGym多位点
  • 冻结特征 → 可尝试LoRA微调ESM-2末层
  • 试题还提到ProtT5、SaProt → 结构感知模型值得对比
  • 反馈独立收益 → 需C0P0/C1P0/C0P1/C1P1四格对照
  • LLM预训练可能见过GB1数据 → 需在新蛋白上验证

9 结论

  1. 构建了Tool-Calling模式的科学智能体，超出Greedy Predictor基线+0.40，首次提供了JSONL日志证据的自主性度量（90%主动工具选择、8/19次策略转折）。
  2. 通过243组系统消融证明：任务结构（而非模型容量）决定特征表示选择。one-hot+RF在此任务上最优，ESM-2 8M≈650M。
  3. 诚实报告负结果并从生物学解释原因：v1 Agent低于Greedy基线、ESM-2在此任务上不如one-hot、逐位点点积信号有限。
  4. 通过双盲统计审计验证全部数据可复现性（10✓/2⚠/0✗）。
