# GB1 首轮实验结果（修订版 v2）

日期：2026-11-09 原始完成，2026-11-14 修订。三随机种子 × 四方法 × 三轮，共 360 条推荐记录。

> **修订说明**：原报告存在统计解释错误（排序方向）、结论强度过高（无显著性检验）、反馈收益证据不足、Agent 自主性范围描述不准确等问题。本版逐项修正，详见[统计与方法复核结论](<../results/reassessment-20261114/统计与方法复核结论.md>)。

## 零实验数据提示下的排序能力（修正方向）

**原报告错误**：将位置与 fitness 的负 Spearman 相关解释为"模型不具备排序能力"。实际排序编码中位置 0 = 最佳，负相关恰好表示高 fitness 变体被排在更靠前的位置，即模型排序方向正确。

**修正后**（转换为高分方向 Spearman）：

| 批次 | 变体数 | 高分方向 Spearman | 批内 Top-10 交集 |
| --- | ---: | ---: | ---: |
| 1 | 50 | +0.2665 | 3 |
| 2 | 50 | +0.2688 | 4 |
| 3 | 50 | +0.1819 | 2 |

三批呈**弱正向排序关系**。小样本且存在 fitness 并列时，不应依据单批渐近 p 值证明排序有效或无效，应使用适合该设计的置换校准。原报告据此声称"没有可用的逐变体排序函数"**缺乏支持**。

自由列举中 10 个变体有 2 个属于全局前十、7 个属于前一百，说明模型存在高分先验，但**无法区分**来源是名单记忆、公开知识、理化规律或相似数据迁移。

## 反馈收益（修正表述）

**原报告问题**：未区分"详细反馈展示效果"与"反馈闭环的独立收益"两个比较目标。

**详细字段展示消融**（三固定状态，共享已更新预测器）：

| 状态种子 | full 减 withheld 下一轮 Top-10 均值 |
| --- | ---: |
| 11 | +0.1405 |
| 22 | +0.8334 |
| 33 | +0.5032 |
| 平均 | +0.4924 |

该结果仅描述详细展示条件在三个固定已更新状态下的观测差异；每状态每条件只有一次生成轨迹，**不足以证明完整反馈闭环具有独立、稳定收益**。

**自适应与冻结流程对照**（三状态均值差 = **−0.008**）：

接近零不等于证明没有收益，但该比较同时改变了训练、上下文和反馈展示，**无法分别识别各部分的作用**。且冻结脚本存在实现不一致（种子 22/33 的纠正抽样使用了种子 11 配置），进一步削弱同条件比较的成立程度。

**结论**：反馈的独立收益**尚未证明**，需补做 C0P0/C1P0/C0P1/C1P1 四格对照实验。

## Agent 自主性范围（修正表述）

| 内容 | 决定者 |
| --- | --- |
| 候选序列、假设和推荐理由 | LLM 在固定 schema 内生成 |
| 观测提供、重训时机、预测器调用 | Python 程序 |
| 格式纠正、评分、Top-k 选择 | Python 程序 |
| 标签查询、轮数、预算与停止 | Python 及外部控制器 |
| 选择工具、看评分后改方案、假设接受/拒绝 | **当前未提供给 LLM** |

**修正**：当前可确认的是候选与假设**内容**的生成自主性，以及程序控制的多轮闭环。工具过程的公开事件由程序 observer 发送，证明程序执行了工具，**不证明 LLM 自主选择了这些工具**。

## 解释范围

随机和模型方法每轮先随机抽取 40 个候选，两种 Agent 自行生成最多 40 个候选。四者共享评分上限和标签查询数。结果来自公开 GB1 四位点空间，模型可能在预训练阶段接触过这些序列与分数。

**可保留的结果**：推荐均值和标签数值、原详细反馈对照差值、校准主均值差的计算均可复现。问题集中在**结论强度、比较设计和可核查记录**。
